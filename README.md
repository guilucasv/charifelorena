# Lorena Charife — Nutrição Clínica & Saúde Digestiva 🌿

Website institucional e landing page profissional da **Dra. Lorena Charife**, nutricionista clínica especializada em Gastroenterologia, modulação intestinal, SIBO, protocolo Low FODMAP e eixo intestino-cérebro em Goiânia/GO.

---

## 📌 Visão Geral

O projeto foi desenvolvido com foco em alta performance, usabilidade móvel, autoridade clínica (E-E-A-T) e SEO local para captação de pacientes particulares, atendimentos online e home care.

Além da página principal, conta com um módulo de gestão interna de eventos e docência.

---

## 🚀 Funcionalidades

### 🌐 Landing Page Principal (`index.html`)
- **Apresentação Profissional & Bio:** Destaque para especializações, formação e abordagem clínica humanizada e baseada em evidências.
- **Áreas de Atuação:**
  - Modulação e Microbiota Intestinal
  - SIBO (Supercrescimento Bacteriano no Intestino Delgado)
  - Protocolo Low FODMAP e Intolerâncias Alimentares
  - Eixo Intestino-Cérebro e Doenças Crônicas
  - Composição Corporal & Longevidade
- **Chamadas para Ação (CTA):** Integração direta com canais de agendamento via WhatsApp e formulários.
- **SEO & Otimização:**
  - Metatags Open Graph completas para compartilhamento em redes e WhatsApp.
  - Dados estruturados JSON-LD (`Schema.org: MedicalBusiness & Nutritionist`).
  - Favicons responsivos multi-resolução para todos os dispositivos.

### 📋 Painel Administrativo de Eventos (`admin-eventos.html`)
- Gerenciamento e organização visual de palestras, aulas em pós-graduação e eventos científicos.
- Interface dedicada, limpa e com identidade visual alinhada à paleta da marca.

## 💻 Como Executar Localmente

Como o projeto é construído em HTML, CSS e JavaScript puros (sem necessidade de compilação ou Node.js):

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/guilucasv/charifelorena.git
   cd charifelorena
   ```

2. **Abrir no navegador:**
   - Dê um duplo clique no arquivo `index.html`; ou
   - Utilize a extensão **Live Server** no VS Code / Antigravity IDE para recarregamento em tempo real.

---

## 🌐 Publicação (Deploy)

O site pode ser publicado gratuitamente em plataformas estáticas:

- **GitHub Pages:**
  > Dica: Se desejar carregar a página principal direto na raiz do GitHub Pages, renomeie `nutri.html` para `index.html` ou configure o redirecionamento.
- **Vercel / Netlify:** Basta conectar o repositório no GitHub que o deploy ocorrerá de forma instantânea.
